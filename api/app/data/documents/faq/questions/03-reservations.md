# Reservas

Para reservar un vehículo, inicie sesión, presione Reservar y pague un depósito de ₡100,000 por SINPE Móvil al número oficial de KPE 8000-0100. Indique el código de reserva en el detalle del SINPE. El personal confirma la reserva en horario de oficina. El depósito se rebaja del precio final.
